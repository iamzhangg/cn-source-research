# Source grading

Use the highest available tier that directly supports the claim.

| Tier | Typical Chinese-web sources | Use |
|---|---|---|
| A | Laws, standards, regulator notices, court documents, official statistics, company filings, product documentation, original datasets | Anchor factual claims |
| B | Named interviews, conference transcripts, established specialist media with direct reporting, peer-reviewed research | Corroborate and add context |
| C | Practitioner posts with disclosed methods, open-source repositories, reproducible benchmarks, long-form community analyses | Leads, implementation detail, qualified evidence |
| D | Aggregators, anonymous posts, copied articles, search snippets, engagement-only rankings | Discovery only |

Independence matters more than domain count. Ten articles copying one press release are one source. Record the original publication date and the date accessed. If an outlet silently updates a page, note the visible update date.

For Xiaohongshu, WeChat, Zhihu, Bilibili, Douyin, and similar platforms, distinguish firsthand experience from market-wide evidence. Engagement can reveal a hypothesis, not prove prevalence.
