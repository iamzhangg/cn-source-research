# CN Source Research / 中文信源研究

[![CI](https://github.com/iamzhangg/cn-source-research/actions/workflows/ci.yml/badge.svg)](https://github.com/iamzhangg/cn-source-research/actions/workflows/ci.yml)

An installable Agent Skill for evidence-backed research across the Chinese web. It grades sources, detects freshness and scope problems, and turns retained evidence into a portable Markdown report.

适合中国市场研究、竞品分析、政策追踪和中文技术调研。它不会把搜索摘要、转载链或单个平台的热度直接当作市场事实。

## What it produces

- Atomic, falsifiable claims instead of a link dump.
- A machine-readable `evidence.json` with source tier, dates, stance, and limitations.
- A readable `evidence.md` generated by a dependency-free validator.
- Explicit separation between sourced facts, contradictions, and inference.

## Install

Copy this repository into your agent's Skill directory, or install with a compatible Skills CLI:

```bash
npx skills add iamzhangg/cn-source-research
```

Then ask your agent to research a Chinese-language or China-market question and produce an evidence pack.

## Demo

```bash
python scripts/render_evidence.py examples/evidence.json --output report.md
python -m unittest discover -s tests -v
```

No Python packages or API keys are required. The detailed source rubric is in [`references/source-grading.md`](references/source-grading.md).
